System Requirements: Locker Rental and Product Sales Manager
Non-Functional Requirements
1. Performance and Availability

NFR1. The system must function offline (without internet).

NFR2. The system must start in less than 5 seconds on the management device.

NFR3. The system must allow any operation (registration, editing, cancellation) to be performed in less than 3 seconds.

2. Usability

NFR4. The system's interface must be intuitive and accessible for users with little to no technical knowledge.

NFR5. The system must include icons and visual elements that facilitate navigation (e.g., colors for locker status).

NFR6. The interface must be optimized for medium screens (laptops).

3. Security

NFR7. The system must protect the editing or deletion of rentals and sales through confirmations or passwords (administrative level).

NFR8. The system must have confirmations to prevent accidental modifications to historical data.

4. Maintainability and Scalability

NFR9. The system must be easy for the developer to update to incorporate future changes based on client feedback.

NFR10. The system must allow exporting data to formats (to be defined: PDF, Excel, .txt).

5. Compatibility

NFR11. The system must be compatible with operating systems Windows (or Linux, to be defined).
