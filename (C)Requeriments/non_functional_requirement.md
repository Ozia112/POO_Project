# System Requirements: Locker Rental and Product Sales Manager

## Non-Functional Requirements (NFR)

**NFR1.** The system must operate offline, start in less than 5 seconds, and perform main actions in under 3 seconds.  
**NFR2.** The interface must be intuitive, suitable for non-technical users, and adaptable to medium and small screens (laptops and tablets).  
**NFR3.** The system must require admin confirmation or password before editing or deleting data.  
**NFR4.** The system must maintain accounting traceability by logging each transaction with timestamp, user, and location.  
**NFR5.** The system must be compatible with Windows and Android, and easily maintainable by the developer.
